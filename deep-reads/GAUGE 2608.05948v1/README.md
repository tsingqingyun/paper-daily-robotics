# GAUGE：仿真引擎与视频世界模型的物理保真度诊断 - L2 精读报告

> [!summary] 一句话判断
> GAUGE 的核心贡献不是证明某个仿真器或世界模型“最好”，而是把“看起来符合物理”拆成真实轨迹误差、方程形式、参数准确性和时间稳定性四类可测诊断；它值得进入具身智能评测基础设施，但目前还没有证明这些诊断分数能预测下游机器人策略的 Sim2Real 表现。

## 结论先行

- **值得保留为核心论文吗？** 是，定位为“物理保真度诊断 benchmark”，不是世界模型能力排行榜。
- **最可信的部分**：真实实验采集与 3 个数值仿真器的跨物理域诊断。真实端包含 22 个任务族、约 1,560 次动捕试验；每个评测任务采集 20 次独立真实试验（PDF p.2、p.10）。
- **最重要发现**：没有一个引擎跨刚体、布料和体积可变形体全面占优；冲击接触、高加速度布料和三维形变是显著弱点（PDF p.10–11，Table 3）。
- **最有洞察力的指标设计**：视频可能呈现正确的方程形状，却恢复出错误的加速度、动量传递和周期；所以“形状拟合好”不等于“物理参数正确”（PDF p.12–13，Table 4、Figure 4）。
- **最需要降权的部分**：世界模型实验未报告多随机种子或重复生成的均值、方差和置信区间；不同模型使用不同原生分辨率、帧率、算力和闭源接口，适合做故障诊断，不适合据此给模型排稳定名次（PDF p.10、p.12、p.29，Table 4、Table 6）。
- **当前可复现状态**：论文描述很细，但截至 2026-08-12，项目页的 Code 与 Dataset 均显示 `Coming soon`；暂时只能审计方法，不能完整复跑结果。

## 1. 论文到底解决什么问题

现有物理评测常落在两端：

1. 用视觉相似度、人类偏好或多模态模型判断视频“像不像真的”；
2. 在单一物体类型或单一物理过程上，用仿真或拟合量作为 ground truth。

两者都难回答一个更有用的问题：**系统具体违反了哪条物理机制，误差来自轨迹、参数、时间尺度，还是接触/形变求解？**

GAUGE 的方案是建立统一的真实测量底座：

- 22 个受控任务族：8 个刚体、1 个绳索、6 个布料、7 个体积可变形体（PDF p.5，Table 2）。
- 物理过程覆盖碰撞、摩擦、动量传递、振荡、自接触、曲率、应变和大形变。
- 真实端提供重复轨迹、测量不确定性和任务关联的物理参数。
- 数值仿真器和生成式视频模型使用两套互补评测协议，共享同一个真实实验基础（PDF p.2，Figure 1）。

这个问题定义是成立的：对于 Physical AI，视觉逼真但动力学错误的环境会诱导策略利用仿真假象，也可能错误排列策略优劣。

## 2. 方法机制

### 2.1 真实测量底座

- 使用 16 台 NOKOV Mars9H 红外相机，覆盖约 `2 m × 2 m × 2 m` 空间，180 Hz 采样，作者报告亚毫米级定位精度（PDF p.9，Figure 3）。
- 刚体通过标记点恢复 6-DoF 位姿；布料和软体通过表面标记构造三角网格并追踪局部形变。
- 每个评测任务采集 20 次独立真实试验，之后截取有效区间并降采样到 30 fps（PDF p.10）。
- 参数不是单纯从待评测轨迹反推：刚体摩擦/恢复系数来自斜面和碰撞实验；布料拉伸、剪切和弯曲来自专用测试；软体 Young 模量与 Poisson 比来自压缩实验和 DIC（PDF p.6、p.21，Figure 7）。

这使 `measurement-grounded` 基本成立。不过，“实验测得参数 → 不同 solver 参数”的映射并不完全等价，见后文公平性审计。

### 2.2 数值仿真器评测

评测 Isaac Sim 6.0、Genesis 1.12 和 Newton 1.3，共 14 个代表任务族（PDF p.6）：

- 刚体分别使用 PhysX、Genesis 原生 solver、MuJoCo。
- 布料分别使用 Surface FEM、PBD、VBD。
- 体积软体分别使用 FEM、显式 MPM、隐式 MPM。
- 实测物理参数写入引擎，其余参数保持默认，不做任务级调优；因此测量的是 **out-of-the-box fidelity**，不是每个引擎调参后的性能上限。

统一轨迹表示为：刚体位置、布料标记点的角亏量/“Gaussian curvature”向量、软体三角面的面积；再计算 RMSE 和 DTW。碰撞和周期任务另加 LSD、MTE、PD、EL（PDF p.7–8，Figure 2）。

### 2.3 视频世界模型评测

定量评测 5 个刚体任务，模型包括 Cosmos3-Nano、Cosmos3-Super-I2V、Wan-2.2、Wan-2.7、Seedance 2.0 和 Genie 3（PDF p.8、p.12）：

1. 输入同一初始图像和标准化文本提示；
2. 由模型生成未来视频；
3. 用 SAM3 分割并跟踪目标，以 mask 质心恢复二维轨迹；
4. 用已知物体尺度把像素轨迹换成度量轨迹；
5. 分别检验方程形式、参数准确性和时间行为。

核心指标包括：

- **DE**：力与运动是否满足 Newton 第二定律；
- **R²**：预期物理方程能否解释生成轨迹；
- **QFI**：加入额外二次项后残差是否显著下降，用于发现错误曲率；
- 任务级参数：加速度、MTE、振荡周期和阻尼等。

这个拆解是论文最值得复用的方法单元。

## 4. 关键结果怎么读

### 4.1 数值引擎：不存在“总体最好”

Table 3 的正确读法不是数 bold 数量，而是看失效机制：

- **普通接触/滑动**：部分任务可以达到或优于真实重复试验内部差异；例如 turntable 上 Isaac 的 normalized RMSE 为 0.17。
- **冲击接触**：bouncing ball 即便最佳结果，RMSE/DTW 仍为基线 15.63/5.58 倍。
- **动量传递**：Newton’s cradle 中 Isaac/Newton 的 normalized MTE 只有 0.20/0.26，Genesis 没有有效 rollout。
- **快速布料**：satin flinging 上 Isaac RMSE 达 128.26，而 Genesis 为 8.54，说明准静态布料表现不能外推到快速形变。
- **体积软体**：即使最佳 solver，许多任务仍比真实试验内部误差高约一个数量级。

因此，选择仿真器应按物理机制和任务 regime，而不是按单一总分。

### 4.2 世界模型：结构正确与尺度正确必须分开

Figure 4 和 Table 4 揭示三类假阳性：

- 轨迹能被直线/抛物线/阻尼正弦拟合，但斜率、加速度或周期错误；
- 视频视觉上像碰撞，却不能产生可测的重复动量传递；
- R² 很高，但实际时间尺度错误。例如 Wan-2.2+negative 与 Genie 3 的摆轨迹 R² 均为 0.99，周期却为 1.93/1.90 s，而真实值是 1.06 s（PDF p.12、p.40）。

这说明世界模型评测至少要联合报告：方程形式、参数、时间尺度和交互事件是否有效。

## 5. 实验可信度与公平性审计

### 做得好的地方

- 真实 ground truth 来自重复实验和专门参数测量，而不是另一个 simulator。
- 把真实试验内部变异作为 normalized error 的参照，比只报绝对轨迹距离更有解释力。
- 附录公开 solver 版本、频率、参数映射公式、模型输入规格、提示词、SAM3 轨迹恢复和任务级公式。
- 世界模型没有把缺失轨迹强行插值；跟踪跳变、停滞和模型生成的几何漂移会保留在指标里（PDF p.34）。
- 论文主动拆分 R² 与实际周期/参数，避免“高拟合分数”掩盖物理错误。

### 会影响结论的限制

1. **默认设置不等于引擎上限。** 除实测参数外保留默认设置，公平地衡量开箱即用表现，但不能证明某 solver 经系统校准后仍然落后。
2. **跨 solver 参数映射包含工程近似。** 布料实测量要映射到不同离散模型；部分使用 isotropic approximation、固定 fallback 或 mesh-specific 初始化，Genesis 还没有独立 shear 输入通道（PDF p.22–23）。因此误差混合了 solver 能力与参数表达能力。
3. **世界模型比较并非完全同条件。** 分辨率、帧率、视频长度、算力和接口不同；Genie 3 的输入也是接口例外（PDF p.10、p.29，Table 6）。
4. **负向提示条件不对称。** Seedance 2.0 与 Genie 3 接口没有 negative-prompt 字段，只能评估无负向提示条件（PDF p.32）。
5. **生成随机性没有充分量化。** 论文没有报告每个 model×prompt×task 的多次生成、随机种子、均值、方差或置信区间；Table 4 更适合作为诊断样本，不足以支撑稳定 leaderboard。
6. **跟踪流程包含输出级人工校准。** 不同输出会单独调整 SAM3 point prompt 和 offset；虽然记录进 JSON，但仍可能引入操作员依赖（PDF p.32）。
7. **二维质心表达有限。** 世界模型只在 5 个刚体任务上定量；slope contact 与 nonsmooth contact 因强三维/不连续状态被排除，布料和体积软体也未进入生成模型定量评测（PDF p.13、p.33）。
8. **没有下游策略验证。** 论文没有测试 GAUGE 分数是否预测机器人策略训练、policy ranking 或真实部署成功率。这是从“诊断 benchmark”走向“机器人基础设施”的关键缺口。
9. **指标文档有一处内部矛盾。** Eq. 17 与 Table 3 caption 都表明 Energy Loss `0` 才是理想守恒，但 Appendix B p.26 的一句文字称“越接近 1 越好”，应是文案错误，复现时必须按公式和表注处理。
10. **曲率指标依赖离散表示。** 附录承认所谓 Gaussian curvature 实际是未按局部面积归一的 angle deficit，并非严格的 `length⁻²` 曲率（PDF p.25）；跨 marker 密度/网格比较要谨慎。

## 6. 作者明确局限与我的补充边界

作者明确承认（PDF p.13）：

- 材料类型与摩擦、刚度、密度、恢复系数、阻尼范围仍有限；
- 没有流体及流固/流软耦合；
- 世界模型轨迹仍是二维，不能覆盖分布式形变、深度、自遮挡和自接触；
- 未来三维重建误差必须显式建模，避免把感知误差误算成生成模型的物理误差。

我的额外边界：

- 受控台架实验具有高可诊断性，但与杂乱场景、主动机器人接触和闭环控制仍有距离。
- GAUGE 目前衡量“rollout 像不像真实物理”，没有衡量一个偏差是否会改变策略梯度、policy ordering 或安全风险。
- 项目页代码和数据尚未开放，因此论文的高方法透明度还没有转化成实际可复现性。

## 7. 对你的研究路线意味着什么

### 应该吸收的原则

- 仿真/世界模型不能只用 FID、感知质量、VLM 打分或主观 plausibility 评测。
- 任何 Physical AI 世界模型评测都应拆分：
  1. **事件有效性**：碰撞/释放/接触是否真的发生；
  2. **方程形式**：轨迹是否符合预期结构；
  3. **参数准确性**：加速度、摩擦、周期、阻尼是否正确；
  4. **时间稳定性**：长 rollout 是否漂移或能量异常；
  5. **下游相关性**：误差是否改变策略训练和真实成功率。
- 选择 simulator 要先建立任务的物理机制画像，再按 regime 选 solver 或做组合验证。

### 不应该得出的结论

- 不能根据 Table 3 宣称 Genesis/Isaac/Newton 中某个“总体最好”。
- 不能根据 Table 4 给视频世界模型做稳定总排名。
- 不能把 GAUGE 上的低轨迹误差直接等价为更好的机器人策略 Sim2Real。
- 不能把高 R² 或低 QFI 单独当作模型学会物理的证据。

## 8. 最小复现与反证实验

### 最值得做的最小复现

选择 `slope slider + bouncing ball + pendulum` 三个刚体任务：

1. 等代码/数据开放后复跑真实轨迹处理与 Table 4 指标；
2. 每个视频模型每个条件至少生成 `N=10`，报告均值、标准差和 bootstrap 95% CI；
3. 固定输入裁剪、时长和随机种子，另外报告 SAM3 跟踪误差；
4. 检查模型排序是否随随机生成和 prompt 小改动翻转。

### 能推翻核心价值的实验

若在多个机器人任务上，GAUGE 的物理误差与真实 policy ranking、成功率下降或安全违规没有稳定相关性，那么它仍是物理诊断数据集，但不能被视为机器人策略选型的有效代理。

### 能把工作推进一层的实验

在 3 个 simulator 中训练同一组策略，测：

- GAUGE task-level error；
- 仿真中的 policy ranking；
- 真实机器人的 policy ranking 与成功率；
- 三者的 Spearman 相关和置信区间。

这会直接回答“基础物理保真度是否足以预测下游 Sim2Real”这一论文尚未回答的问题。
