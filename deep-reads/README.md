# 精读论文库

每篇论文独立维护一个目录：

- `README.md`：L1/L2 精读报告，关键判断绑定页码、表格或图。
- `manifest.json`：论文标识、阅读层级、完成状态、原文地址与本地 PDF 校验值。
- 原文 PDF：可保存在对应本地目录；默认不重复发布到 GitHub。

只有 `reading_status: processed` 的报告进入 GitHub `deep-reads/`。本地总入口是 `50_Papers/精读论文索引.md`。
