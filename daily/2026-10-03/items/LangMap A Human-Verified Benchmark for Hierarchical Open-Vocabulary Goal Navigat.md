# LangMap: A Human-Verified Benchmark for Hierarchical Open-Vocabulary Goal Navigation

> [!summary] 这篇论文到底做了什么（基于摘要）
> LangMap 把导航目标从“找某类物体”扩展到场景、房间、区域和具体实例，并用人工核验的描述减少目标歧义。它的关键做法是比较同一场景里容易混淆的候选目标，写出能区分它们的语言。

## 问题

任务是让智能体仅凭用户指定的目标自行导航，无需逐步指路。现有基准多只测物体类别，或使用视觉语言模型生成的实例描述；后者可能有语义错误或指向多个对象，导致导航失败究竟来自智能体还是题目本身难以判断。

### 用一个例子理解

理解用例（非论文实验）：输入“去窗边阅读区那张放着蓝色靠垫的椅子”，智能体根据 RGB 观察和记忆探索，规划接近相关区域，再由策略向具体椅子移动并停止。输出是到达目标的导航行为；这同时要求找到区域、区分实例和选对停止时机。

## 创新点或方法

本文定义四层目标的 HieraNav 任务，在 HM3D 室内三维扫描上构建 LangMap。标注时对比同场景的区域和实例，并为目标提供简短、详细两种描述，再由人核验。另给出 RGB-only 基线 PlaNaVid，用 Bounded Diverse Memory 配合高层规划引导反应式策略完成多目标导航。标注流程属于基准构建；策略训练细节未说明，运行时怎样维护记忆和制定计划也需要查正文。

### 方法如何工作

1. 把目标分为四个语义层级，使测试能区分找场景、房间、区域和具体对象的能力。
2. 对比同场景候选区域与实例，写出区分性描述，降低多个目标都符合指令的风险。
3. 为目标提供两种描述长度并人工核验，让指令风格和描述正确性能够分别检查。
4. 运行导航基线并分析不同目标层级的失败，从而定位探索、消歧和停止等具体瓶颈。

### 必要术语

- 开放词汇目标：目标不限于固定的少数类别标签；本文允许更丰富的语言描述。
- 层级消歧：逐层确定语言指向哪个位置或对象；本文用四层目标检验这种能力。
- 文本到视图匹配：判断描述对应哪个视觉目标；本文用它检验标注质量。

## 证据

摘要报告覆盖 414 个物体类别、超过 18K 个任务。在与 GOAT-Bench 共享的全部已标注实例上，描述的文本到视图匹配准确率高出 23 个百分点；独立人工审查得到 92.5% 的唯一且正确匹配。这支持描述可靠性改善，不能直接等同于导航成功率改善。PlaNaVid 被报告达到领先一档的成功率，且不使用深度、三维场景表示或物体掩码，但摘要未列具体成功率和对比方法。环境源于真实扫描，摘要未报告真机导航。

## 局限

作者的分析明确指出，目标越细，探索与层级消歧失败越突出，长尾类别、小物体、远处目标、及时停止和多目标完成仍困难。我的待核查问题是人工审查的抽样与判定规则，以及不同层级的任务难度是否可比；92.5% 也意味着描述可靠性并非完美。

- **判断**：值得先读标注协议和失败分析，再读 PlaNaVid；这篇最直接的用途是建立更可信的导航测试，而不是仅凭摘要选定导航算法。

## 研究关联

可借鉴的是先检验任务语言是否能唯一指向目标，再评价智能体。尤其当指令从类别细化到某个区域或实例时，“描述听起来合理”远远不够；与同场景候选项做对比，才能检查它是否提供了真正有用的区分信息。

### 下一步读哪里

核查四层目标的成功判定、对比标注协议和人工审查样本；再看各层级成功率与失败分解。对 PlaNaVid，应检查记忆如何限制容量并保持多样性，以及规划是否真正改善多目标完成。

### 原始摘要

arXiv:2602.02220v3 Announce Type: replace-cross Abstract: Language-conditioned goal navigation (LGN) requires embodied agents to locate user-specified targets without step-by-step guidance. However, existing benchmarks largely focus on category-level goals or rely on instance descriptions generated by vision-language models, which often contain ambiguities and semantic errors, limiting systematic and reliable evaluation. We introduce HieraNav, an open-vocabulary LGN task with goals at four hierarchical semantic levels: scene, room, region, and instance. We present Language as a Map (LangMap), the first LGN benchmark to enrich real-world indoor 3D scans with human-verified semantic annotations supporting tasks across all four goal levels. Built on HM3D using a contrastive annotation protocol that compares same-scene regions and instances, LangMap provides region labels and discriminative region and instance descriptions covering 414 object categories and contains over 18K tasks. Each target has concise and detailed descriptions, enabling evaluation across instruction styles. Automated and human evaluations validate our annotation quality: our descriptions improve text-to-view matching accuracy over GOAT-Bench's by 23 points on all shared annotated instances, and an independent human audit yields 92.5% unique-and-correct matches. We also propose PlaNaVid, an RGB-only baseline that combines Bounded Diverse Memory with high-level planning to prime a reactive policy for multi-goal navigation, achieving top-tier success rates without depth, 3D scene representations, or object masks. Further analyses reveal that exploration and hierarchical disambiguation failures become more prominent at finer goal levels, while long-tail categories, small objects, distant targets, timely stopping, and multi-goal completion remain challenging. Benchmark and code: https://bo-miao.github.io/LangMap
