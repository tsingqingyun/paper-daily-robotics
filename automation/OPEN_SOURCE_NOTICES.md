# Open-source workflow attribution

The paper-explanation stage adapts the evidence-first review structure from:

- Project: `Nech07/dailypaper`
- Source: https://github.com/Nech07/dailypaper
- Reviewed revision: `251d41527dc6bab4df84eda027d573538323e967`
- Relevant source: `skills/daily-papers-review/SKILL.md`
- License: Apache License 2.0

Adapted ideas include separating the core method, research relevance, evidence-bounded
review, and an explicit verdict. This project uses a shorter abstract-only schema and
adds a fail-closed semantic quality gate for unattended daily publication.

The upstream Apache-2.0 license is available at:
https://github.com/Nech07/dailypaper/blob/main/LICENSE
